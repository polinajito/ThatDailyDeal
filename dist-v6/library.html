Spacing

4px base scale. Each bar's width equals the token value so the relative steps are visible at a glance. Use these for padding, margin, and gap throughout.

Border radius

Discrete radius scale. Reach for --radius-pill on capsule buttons and banners, --radius-circle for avatars and icon buttons, the rest by visual weight.

Shadows

Drop shadows for elevation. --shadow-sheet casts upward (used by bottom sheets). --shadow-gold-glow is the accent glow under the primary CTA.

Liquid glass

Translucent surfaces composited over the page behind them. Primary glass is reused across the deals banner, price pill, action buttons and bottom nav. The subtle variant is for toasts and inline overlays.

Price pill

Liquid-glass pill at the top of each deal card showing product name, current price, and (when applicable) the strikethrough old price + discount badge. Three states: regular (just the now-price), with sale (now + old + discount), and out of stock (strikethrough now-price, muted weight).

Source: v6.css:622-658 (.price-pill, .pp-name, .pp-now, .pp-old, .pp-discount); v6.css:1124-1128 (sold-out variant). Uses tokens: --glass-bg, --glass-border, --glass-blur, --glass-shadow, --color-white, --color-red, --font-family-primary.

Button

Composable button. Pick a color (.btn-primary = gold, .btn-secondary = blue), a size (.btn-sm / .btn-md / .btn-lg), optionally a fill modifier (.btn-ghost for outlined), and optionally .btn-icon-only for square icon buttons. The .btn-glass modifier swaps the solid bg for liquid glass — designed for the action-stack pattern. Icon position is determined by DOM order (icon first = left, icon last = right).

Source patterns in prototype: v6.css:318-342 (.dd-btn), v6.css:1177-1194 (.card-cta), v6.css:575-612 (.act-btn). Tokens: --color-gold, --color-blue, --color-white, --glass-*, --radius-pill, --font-family-primary, --shadow-gold-glow.

Red fill (.btn-destructive) for irreversible confirmations — log out, delete account. Composes with .btn-ghost for a softer outlined variant.

.is-disabled dims the button and drops its shadow. Visual only — the element stays clickable (pair with aria-disabled) so a tap can explain why it's inert, rather than the silent native disabled attribute.

Deals banner

The pill-shaped "Today's deals end in HH:MM:SS" countdown that sits just below the price pill on each deal card. Centered content, clock icon + label in white, the live timer in red. Hidden globally when body.no-banner is set.

Source: v6.css:136-169 (.deals-banner, .deals-banner-icon, .deals-banner-time); markup in v6.js renderCard. Tokens: --glass-bg, --glass-border, --glass-blur, --glass-shadow, --radius-pill, --color-red, --font-family-primary.

Swipe stamps

Large rotated overlays that flash on a deal-card during a swipe-up gesture, or persist on sold-out cards. (Horizontal swipes now navigate between deals and show no stamp.) Variants signal intent: green Add (swipe up on an available deal), gold Notify (swipe up on a sold-out deal), red Sold Out (persistent, centered). The red Skip variant is retained but currently unused by the gesture model.

Visual: components.css (.swipe-stamp, .stamp-add, .stamp-skip, .stamp-soldout, .stamp-notify). Visibility (.deal-card.show-add, .show-notify, .sold-out) is owned by v6.css. Tokens: --color-green, --color-red, --color-gold, --space-2, --space-4, --space-5, --radius-md.

Toast

Two transient overlays. The small tap toast is an unobtrusive black pill for one-off feedback (liked, link copied, added to cart) — fires for ~1.3s. The rich toast is a higher-stakes confirmation card with icon + title + supportive text (currently: "We'll notify you when this item is back in stock") — fires for ~2.8s.

Visual: components.css (.toast, .rich-toast, .rich-toast-icon, .rich-toast-title, .rich-toast-sub). Positioning + slide-in stays in v6.css; fired by showToast() / showRichToast() in v6.js.

Info popup

Brand-blue card centred on the screen behind a dimming backdrop, pairing the brand logo with a sentence of copy. Carries a top-right close (X) and a gold "Okay, cool" CTA (.btn.btn-primary). In the prototype it's opened by tapping the header flag ("America based, serving up deals since 2009.") and dismissed by the X, the CTA, tapping the backdrop, or pressing Escape.

Visual: components.css (.info-popup, .info-popup-logo, .info-popup-text, .info-popup-close, .info-popup-cta). Centring, backdrop, and open/close transition stay in v6.css; toggled in v6.js via the body.flag-popup-open state.

Challenge card

Full-bleed promo card that rides the deal filmstrip as an interstitial (3rd card). Brand-green gradient surface with a "Play & Win" badge, money-bag hero, headline + copy, two reward chips, and a gold "Start a Challenge" CTA (.btn.btn-primary). It only navigates horizontally — no swipe-up or tap-to-details — and the CTA shows a placeholder toast.

Visual: components.css (.challenge-card + .challenge-badge, -hero, -title, -sub, -rewards/-reward, -cta, -foot). Deck sizing (full width/height, touch-action) shared with .deal-card in v6.css; built + spliced into the sequence in v6.js (buildChallengeCard, SEQUENCE).

Challenge mini

Compact, horizontal sibling of the challenge card for list contexts like the Contests tab. A lighter-green top band pairs the money-bag hero with an eyebrow, headline, and one-line copy; a darker-green footer band carries the two reward stats inline (amount over uppercase label) rather than as white chips.

Visual: components.css (.challenge-mini + -top, -hero, -anim, -text, -eyebrow, -title, -sub, -rewards/-reward, -amount, -label). Rendered into the Contests tab by contests.js; the loopmoney hero loads via window.playLoopmoney (assets/loopmoney.js).

List card

Grouped liquid-glass list for settings-style screens. A .list-card stacks .list-row items separated by hairline dividers. Each row takes an optional leading .list-row-icon, a .list-row-text block (.list-row-label + optional .list-row-sub), and a trailing slot — a gold .list-row-chevron disclosure arrow or a control (reuse the .ns-switch toggle). Tappable rows are <button>; rows whose control owns interaction use .is-static. .list-row-destructive turns the label red for irreversible actions.

Visual: components.css (.list-card, .list-row, .list-row-icon, .list-row-text, .list-row-label, .list-row-sub, .list-row-chevron, .list-row-destructive). Reuses the .ns-switch toggle. Tokens: --glass-*, --radius-lg, --radius-sm, --color-white, --color-gold, --color-red, type scale.

Form field

Labelled text input for the dark glass surface (settings detail pages). A .field stacks a .field-label over a .field-input; drop .field rows inside a .list-card for a grouped form with hairline dividers. Focus draws a gold border + soft ring. A readonly input reads as a static value (no ring), for non-editable rows like "Member since".

Visual: components.css (.field, .field-label, .field-input). Reuses .list-card as the form container. Tokens: --glass-*, --radius-sm, --color-white, --color-gold, type scale.
