Spacing

4px base scale. Each bar's width equals the token value so the relative steps are visible at a glance. Use these for padding, margin, and gap throughout.

Border radius

Discrete radius scale. Reach for --radius-pill on capsule buttons and banners, --radius-circle for avatars and icon buttons, the rest by visual weight.

Shadows

Drop shadows for elevation. --shadow-sheet casts upward (used by bottom sheets). --shadow-gold-glow is the accent glow under the primary CTA.

Liquid glass

Translucent surfaces composited over the page behind them. Primary glass is reused across the deals banner, price pill, action buttons and bottom nav. The subtle variant is for toasts and inline overlays.

Price pill

Liquid-glass pill at the top of each deal card showing product name, current price, and (when applicable) the strikethrough old price + discount badge. Three states: regular (just the now-price), with sale (now + old + discount), and out of stock (strikethrough now-price, muted weight).

Source: v6.css:622-658 (.price-pill, .pp-name, .pp-now, .pp-old, .pp-discount); v6.css:1124-1128 (sold-out variant). Uses tokens: --glass-bg, --glass-border, --glass-blur, --glass-shadow, --color-white, --color-red, --font-family-primary.

Button

Composable button. Pick a color (.btn-primary = gold, .btn-secondary = blue), a size (.btn-sm / .btn-md / .btn-lg), optionally a fill modifier (.btn-ghost for outlined), and optionally .btn-icon-only for square icon buttons. The .btn-glass modifier swaps the solid bg for liquid glass — designed for the action-stack pattern. Icon position is determined by DOM order (icon first = left, icon last = right).

Source patterns in prototype: v6.css:318-342 (.dd-btn), v6.css:1177-1194 (.card-cta), v6.css:575-612 (.act-btn). Tokens: --color-gold, --color-blue, --color-white, --glass-*, --radius-pill, --font-family-primary, --shadow-gold-glow.

Deals banner

The pill-shaped "Today's deals end in HH:MM:SS" countdown that sits just below the price pill on each deal card. Centered content, clock icon + label in white, the live timer in red. Hidden globally when body.no-banner is set.

Source: v6.css:136-169 (.deals-banner, .deals-banner-icon, .deals-banner-time); markup in v6.js renderCard. Tokens: --glass-bg, --glass-border, --glass-blur, --glass-shadow, --radius-pill, --color-red, --font-family-primary.
